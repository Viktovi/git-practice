## Опис проєкту
Репозиторій створено для практики роботи з Git і GitHub.

## Призначення
Навчальний приклад роботи з комітами, гілками та структурою репозиторію.

## Структура
- **src/** — вихідні файли (main.py)
- **docs/** — документація (опис, звіти)
- **assets/** — допоміжні файли (зображення, ресурси)
